Election Timeline

Elections ela jaruguthayo step-by-step process chudandi.

1

Announcement & Code of Conduct

Election Commission dates announce chestundi. Appati nunchi Model Code of Conduct (MCC) amalu loki vastundi.

2

Nominations

Candidates valla nominations file chestaru. Scrutiny tarvata final list publish avthundi.

3

Campaigning

Parties pracharam chestayi. Voting roju ki 48 hours mundu pracharam aagipovali (Silence period).

4

Polling Day

Voters EVMs dwara valla vote vestaru. Polling strict security lo jaruguthundi.

5

Counting & Results

EVMs ni open chesi votes count chestaru. Highest votes vachina candidate gelustaru.
