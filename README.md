# ElectionIQ 🗳️

An interactive chatbot that helps Indian users understand 
the election process in a simple, conversational way.

## Features
- Voter registration process
- How EVM machines work
- Election timeline and phases
- Step-by-step voting day guide
- How results are counted
- Role of Election Commission of India
