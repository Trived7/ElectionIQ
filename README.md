# ElectionIQ 🗳️

An interactive dashboard that helps Indian users 
understand the election process in a simple, 
engaging way.

## Features
- 💬 AI Chat — ask anything about Indian elections
- 📅 Timeline — visual step-by-step election phases
- 🧠 Quiz mode — test your election knowledge
- 🌐 Hinglish content — relatable for Indian users
- 🎨 Premium UI — tricolor neon theme
